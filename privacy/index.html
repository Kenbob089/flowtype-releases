Privacy

Flowtype collects nothing. It has no accounts, no analytics and no network connections.

What is stored

Settings, the current text, saved texts, typing profiles, your learned typing style, the typing test best and the history of typed texts are saved in a settings file in a folder on your own computer. The About window shows the exact location. History can be switched off in Settings, and the emergency close wipes it. Backups are files you create and keep yourself.

Removing the data

Choose Clear all data in the About window to delete the settings file and close the app, or delete the .exe and its data folder.

This website

This site is a set of static pages. It sets no cookies and runs no trackers. Fonts are loaded from Google Fonts. Downloads are served from the project's release page on GitHub.
