FlowtypeOverviewDownloadsGuideChangelog

What is new.

Every version of Flowtype, newest first. Get any of them from the downloads page.

Version 1.11.1 beta 5 Beta

  • Number boxes and other controls no longer show up as stray boxes in the mini window: every control the layout does not use is hidden and parked out of sight before each repaint

Version 1.11.1 beta 4

  • Fixed the text box reappearing in the Status mini style (and flashing when opening): refreshing the editor switched its visibility back on. Hidden controls are now also parked out of sight

Version 1.11.1 beta 3

  • Long descriptions in Settings wrap onto more lines instead of being cut off
  • Switching the mini style in Settings no longer leaves the text box showing in the Status style; hidden controls are now checked every time
  • Settings → Mini: Start Flowtype in mini mode, which opens straight into the mini window
  • Status style: a smaller status dot and a small round Expand button with an icon
  • F5 switches between Normal, Natural and Hand mode while Flowtype is in front (on by default, switch it off in Settings → General)

Version 1.11.1 beta 2

  • Status mini style has no text box, a small Expand button at the bottom and a centred play icon
  • Default mini style gives the room of hidden settings to the text box instead of shrinking the window
  • Time left and the estimated finishing time no longer drift while typing is paused
  • Christmas finishes with falling snowflakes only
  • Typing test: Paragraph, Words (1 to 999 words or no limit, finish any time) and Timed (15 s to 2 min, endless words) modes, and a button to show or hide the ghost

Version 1.11.1 beta 1

  • Mini mode has two styles, chosen in Settings → Mini: Default (the compact settings you know) and Status, a centred panel with a big status dot, the status, characters left, the estimated finishing time and play and stop buttons (play turns into pause while typing)
  • In the Default mini style, a small arrow at the top right of the settings hides them with a smooth animation, and a small arrow at the bottom right brings them back
  • Explore (View → Explore) with a typing test: race a ghost that types at your best speed, with live speed, accuracy and time, and a new best when you beat it
  • Optional chime when typing finishes (Settings → Misc, off by default)
  • Festive themes now have their own celebration: fireworks, falling snow, drifting leaves and more, instead of the same confetti
  • Natural mode can copy how you slip: learn my typing style now notices whether your typos are neighbouring keys, swapped letters, doubled letters or skipped letters, and Natural mode makes the same kinds

Version 1.11 Download

  • New Settings window (File → Settings or Ctrl+,) with Mode, Timing, General and Misc pages; long pages scroll and numbers can be typed
  • Learn my typing style: type a short paragraph in a typing-test style window and Natural mode adopts your minimum, average and maximum speed, pauses and typo habits. Reapply it any time
  • Natural speed stays between your minimum and maximum, drifts gradually and aims for your average. The first keys no longer run fast, and the speed you set is the speed you get
  • Natural setting: chance to not notice an error, also learned from how you type
  • Bold, italic and underlined text is typed with its formatting (Ctrl+B, Ctrl+I, Ctrl+U) in every mode; it can be switched off in Settings
  • History window (View → History or Ctrl+H): the texts you have typed, newest first, to load again. It can be turned off, and the emergency close wipes it
  • Right-click menu for the text box: undo, redo, cut, copy, paste, select all, formatting, find, history and clear
  • Confetti when typing finishes, with an optional emergency-close shortcut (rebindable, Ctrl+Shift+X by default) and an optional auto-close timer that never closes Flowtype while it types or while you use it
  • Festive themes with their own shapes, true holiday colours, a festive strip, confetti and theme-card emblems
  • New Black theme: true black with a white accent in dark mode, white with a black accent in light mode
  • Themes can follow the Windows dark or light setting with the System switch
  • Hand mode and Natural mode switch each other off; Hand mode has a short note and a smaller mini window
  • Backups moved to Settings → General, with a core settings backup (no saved texts, typing style or text box)
  • Shorter How to use and Welcome text

Version 1.10

  • Hand mode: arm it with the start key, then every key you press types the next characters of your text (1 to 20 per key)
  • Natural mode now presses real keys (virtual key and scan code), so apps and key testers see actual keystrokes instead of unknown input

Version 1.9

  • The app is now called Flowtype, with a new icon
  • Existing settings, texts and profiles carry over automatically
  • Backups made before the rename can still be restored

Version 1.8.1

  • Mini mode is one fixed, compact size in both classic and Natural mode
  • Deeper Violet theme
  • [pause 3] text tag
  • Tooltips on controls
  • Restore from backup can merge instead of replace
  • Fixed borders around undo and redo in light mode

Version 1.8

  • Backups include the theme they were saved with
  • Clear all data in the About window
  • Welcome window on first launch
  • Shorter status messages in mini mode and a redesigned mini settings panel
  • “Activation key” renamed “Start Key”; “Simulate human errors” renamed “Errors”

Version 1.7.2

  • Start-in-N-seconds countdown
  • Progress bar and time left in mini mode
  • Custom hotkey capture
  • Import and export .txt files, back up and restore everything
  • Pauses instead of stopping when another window takes focus

Version 1.7.1

  • Clear formatting button
  • Stronger light themes
  • Popup windows use the app icon

Version 1.7

  • Named typing profiles with Slow, Regular, Fast and Natural presets
  • Separate save and load for texts and profiles in the File menu

Version 1.6

  • Mini mode
  • Natural mode and light/dark theme families with a Themes window
