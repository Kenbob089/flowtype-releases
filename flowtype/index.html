Three steps and it is typing.

Add the text.

Type or paste it into the big box. Pick a profile or a mode if you want one.

Click the target.

Click into the window or field where the text should appear.

Press the start key.

F9 by default. Press it again to stop; F10 pauses and resumes.

It can type like you.

Natural mode adds thinking pauses and believable slips, then fixes them. Type one short paragraph and Flowtype measures your slowest, average and fastest speed, how often you pause and how you make typos. Natural mode copies all of it.

Everything else it does.

Simple to start, with the controls that matter when you need them.

Hand mode

Press any key and the next characters of your text appear instead. You set the pace with your own fingers.

Formatting kept

Bold, italic and underline are typed as Ctrl+B, Ctrl+I and Ctrl+U where each style starts and ends.

History

Every text you typed, newest first, one click to load it again. Switch it off any time.

Typing profiles

Slow, Regular, Fast and Natural, plus your own saved setups.

Delay and loop

A countdown to click the target, and a loop with random waits.

Safe by default

Typing pauses when another window grabs focus, and an emergency key stops it at once.

Your own hotkeys

Any combination for start and pause, such as Ctrl+Shift+T.

A real editor

Find and replace, undo and redo, saved texts, import and export, and a right-click menu.

Typing test beta

Race a ghost in a paragraph, a word count or against the clock, from View → Explore.

Festive themes

Holiday themes with their own shapes, colours and a celebration when typing ends.

Backup and restore

One file holds everything. Merge it back in or replace what you have.

F5 mode switch beta

Flip between Normal, Natural and Hand mode while Flowtype is in front.

Questions.

Does it work in every program?

It sends normal key presses, so it works almost anywhere you can type: documents, forms, chats and editors. Windows running as administrator ignore keys from a normal program unless the app is also run as administrator.

Does it collect any data?

No. Settings, text, saved texts, history and profiles are stored in a file on your own computer, and the app makes no network connections.

Why does typing sometimes pause?

Typing pauses when another window takes focus, so nothing lands in the wrong place. It continues when you come back. This can be turned off in Settings.

Windows shows a SmartScreen warning. Is that normal?

Yes. The app is a small independent program and is not code-signed yet, so Windows warns about it. Choose More info, then Run anyway.

How do I stop it right now?

Press the start key again, or the emergency shortcut (Ctrl+Shift+X by default). The emergency shortcut also clears the text box and the history, then closes the app. It can be changed or switched off in Settings.

Can I back up or move my data?

Yes. Settings → General can back up everything, or just the core settings, and restore either one later.

How do I remove it?

Open About and choose Clear all data to wipe the settings, then delete the .exe. Nothing else is installed.
