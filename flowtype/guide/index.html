Getting started

  1. Type or paste the text into the big box.
  2. Click into the window or field where the text should appear.
  3. Press the start key (F9 by default). Press it again to stop; the pause key pauses and resumes.

Start delay waits a number of seconds first and counts down in the status pill, leaving time to click into the target window. Loop typing repeats the text after a random wait between a minimum and a maximum. Both live in Settings → Timing. Click a number in Settings to type a value instead of using the arrows.

Hotkeys

Click the Start Key or Pause Key box and press any combination, such as Ctrl+Shift+T. Esc cancels. Keys that type something need Ctrl, Alt or Win; F-keys can be used alone. Open Settings with Ctrl+,.

Modes

Settings → Mode has three modes. Normal types at a set speed. Natural types like a person. Hand types when you press keys. Natural and Hand mode switch each other off, and the settings of the active mode appear right below the mode buttons.

Natural mode

Variable speed lets the pace drift within a range of words per minute: gradually, never in jumps, always between the slowest and fastest speed, and aiming for your average when a typing style is learned. Pause % is the chance of a short thinking pause after a word. Realistic errors adds slips such as wrong neighbouring keys, swapped, doubled or missed letters, which are noticed after a few characters and corrected. Rate % sets how often, Notice how many letters are typed before a slip is caught, and Chance to not notice how often a slip is left in the text.

In Natural mode every character that has a key on the current keyboard layout is pressed as a real key (with Shift when needed), so applications see genuine keystrokes. Characters without a key, such as emoji, are sent as Unicode input.

Learn my typing style

Settings → Mode → Natural → Learn my typing style opens a typing test. Type the paragraph shown; Flowtype measures your slowest, average and fastest speed, how often you pause, and how you make and fix typos, including which kind of slip you make most (a neighbouring key, swapped, doubled or skipped letters). Choose Use my style to put it into Natural mode. Different paragraph shows another one, and the round arrow restarts the current paragraph. If you change Natural settings afterwards, a Reapply button brings your learned style back.

Hand mode

Pick Hand mode in Settings → Mode. Press the start key to arm it, then press any letter, number or punctuation key in the window to type into: each press types the next characters of the text instead of the key pressed. Choose 1 to 20 characters per key press in Settings. Enter, Backspace, Tab, arrows, F-keys and shortcuts with Ctrl, Alt or Windows keep working. The pause key lets your own keys through for a moment, and the start key turns Hand mode off.

Formatting

Bold, italic and underlined text is typed with its formatting: Flowtype presses Ctrl+B, Ctrl+I or Ctrl+U where a style starts and ends, then turns it off again for the next keys. This works in every mode. In apps where those shortcuts do something else, turn off Type bold, italic and underline in Settings → General.

History

Open it with View → History or Ctrl+H. Each time typing starts, the text is added at the top (the same text again just moves up). Click an entry or Use to put it back in the text box, or delete entries one by one. Settings → General turns history off and clears it. The emergency close wipes it too. Texts longer than 20,000 characters are not recorded, and the list is kept small.

Typing profiles

Slow, Regular, Fast and Natural are built in. Save typing profile (File menu) stores a custom speed, delay, loop, error and Natural setup under a name. Profiles are separate from saved texts, which keep text and its formatting.

Mini mode

Press Ctrl+M or use the View menu. Flowtype becomes a small always-on-top panel with the status, the text and the essential settings. While typing it shows a progress bar with characters typed and the time left. Expand returns to the full window.

1.11.1 beta Settings → Mini picks the style and can start Flowtype in mini mode. F5 switches between Normal, Natural and Hand mode while Flowtype is in front. Default keeps the compact settings under the text; the small arrow at the top right of that panel hides it, and the arrow at the bottom right brings it back. Status replaces the settings with a centred panel: a large status dot, the status, characters left, the estimated finishing time, and play and stop buttons. Play becomes pause while typing.

Explore 1.11.1 beta

View → Explore holds extras. The Typing test races you against a ghost that types at your best speed (or the speed Flowtype learned from you, or an average typist if there is neither). Type the paragraph; beating the ghost with at least 90% accuracy sets a new best. Choose Paragraph (a real paragraph), Words (1 to 999 random words, or no limit and finish whenever you like) or Timed (15 seconds to 2 minutes of endless words). A button shows or hides the ghost. The round arrow restarts the text.

Themes

File → Themes has ten colour families in light and dark, plus eight festive themes (turn them on in Settings → General). Choose System to follow the Windows dark or light setting. Pick an accent colour to override the theme's own. Click a swatch on the overview page to preview. When typing finishes, festive themes celebrate with their own show (fireworks, snow, leaves and more). Settings → Misc also has an optional chime that plays at the end, off by default.

Text tags

Two tags work inside the text and are never typed themselves:

  • [clipboard] is replaced by whatever is on the clipboard at that moment.
  • [pause 3] stops typing for 3 seconds at that spot. Any number works, such as [pause 0.5], up to 600 seconds.

Safety

If another window takes the focus while Flowtype types, typing pauses and continues when the window is back in front. This can be turned off in the settings. The emergency shortcut (Ctrl+Shift+X by default, changeable in Settings → Misc) stops typing, clears the text box and the history and closes Flowtype. An optional auto-close timer closes Flowtype after a period of inactivity, but never while it types or while you are using it. Windows running as administrator ignore keys from a normal program unless Flowtype is also run as administrator.

Your data

In Settings → General, Back up everything saves settings, texts, typing style and the text box into one file, and Back up core settings saves only the settings. Restore from backup can merge or replace. Import loads a .txt file into the box and Export saves it. Clear all data in About deletes everything and closes the app.
